Build a production-quality mobile-first document photo enhancement application.

IMPORTANT:
This application is NOT an AI image generator.
It must enhance the existing uploaded document/photo while preserving the original text, numbers, names, signatures, stamps, seals, logos and document structure.

The primary use case is photographed/scanned legal, government, trademark, court, business and official documents that are captured with poor lighting, dull exposure, grey background, shadows, slight perspective distortion or low contrast and need to be printed clearly.

The application should feel like a polished Android/iOS mobile app, even if implemented as a responsive web/PWA application.

==================================================
1. APP NAME
==================================================

Use a professional temporary name:

"DocBright"

Subtitle:

"Document Photo Enhancer"

The branding should be clean, professional and document-focused.

Do NOT make it look like a generic photo editor.

==================================================
2. CORE OBJECTIVE
==================================================

The user should be able to:

1. Upload one document image.
2. Upload multiple document images in bulk.
3. Automatically enhance them.
4. Compare original vs enhanced.
5. Manually adjust enhancement settings if required.
6. Export individual images.
7. Export all processed images together.
8. Keep original files untouched.
9. Process documents without changing their actual content.

The main goal is:

DULL DOCUMENT PHOTO
        ↓
AUTO DOCUMENT ENHANCEMENT
        ↓
CLEAN + BRIGHT + READABLE DOCUMENT
        ↓
PRINT READY OUTPUT

==================================================
3. VERY IMPORTANT DOCUMENT SAFETY RULE
==================================================

This application is intended for official and legal documents.

Therefore:

DO NOT use generative AI to redraw, rewrite, recreate or hallucinate document content.

DO NOT replace text.

DO NOT OCR-reconstruct the document.

DO NOT invent missing characters.

DO NOT alter names, dates, registration numbers, signatures, stamps, seals, logos or legal wording.

Image enhancement must operate on the existing pixels.

The application should prioritize image-processing techniques such as:

- brightness correction
- contrast enhancement
- exposure correction
- white balance
- shadow reduction
- highlight recovery
- denoising
- sharpening
- grayscale conversion
- adaptive thresholding
- background whitening
- perspective correction
- deskew
- document cropping

AI enhancement, if added later, must NEVER regenerate document content.

22. STORAGE / PRIVACY
==================================================

Documents may contain sensitive legal information.

Therefore:

Prefer local/on-device processing whenever technically possible.

Do not upload document images to an external AI service by default.

Do not send documents to third-party image generation APIs.

Do not store documents permanently on a server unless explicitly required.

If server processing is technically required:

- clearly explain it
- use secure temporary storage
- automatically delete temporary files
- never use uploaded documents for training

Add a small privacy message:

"Your documents are processed locally whenever possible. Original files are never modified."
