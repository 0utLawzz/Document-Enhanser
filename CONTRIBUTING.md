# Contributing to Document Enhancer

First off, thanks for taking the time to contribute! 🎉

## Getting Started
1. **Fork** the repository on GitHub.
2. **Clone** your fork locally.
3. Install dependencies by running `pnpm install` in the root directory.

## Making Changes
- Create a new branch from `main`.
- Make your changes in the appropriate directory (e.g., `artifacts/docbright-web`).
- Ensure your code follows the existing style guidelines and passes any formatting or linting checks.
- Add tests if applicable.

## Submitting Pull Requests
- Push your changes to your fork.
- Open a Pull Request against the `main` branch.
- Provide a detailed description of your changes and why they are necessary.

## Reporting Bugs
If you find a bug, please create an issue detailing:
- The steps to reproduce the bug.
- The expected behavior vs. what actually happened.
- Any relevant logs or screenshots.

Thank you!
